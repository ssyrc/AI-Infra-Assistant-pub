# AI Infra Assistant

사내 인프라/시스템 운영을 돕는 한국어 에이전트. 매뉴얼·과거 문의(VOC) 검색과 커맨드 실행을
MCP 도구로 묶고, **확인한 것만 답하도록** 여러 층의 안전장치를 둔다.

- `agent_server/` — OpenAI 호환 API. 매 질문마다 매뉴얼·VOC를 먼저 검색해 근거를
  프롬프트에 넣고(선검색), 답변에 근거 없는 값이 있으면 그 줄을 덜어낸다.
- `mcp_servers/` — Manual · VOC · Execution · Chart MCP.
- `shared/` — 검색·실행·설정·마이그레이션 등 공용 코드(검색 경로는 한 벌만 둔다).
- `admin_console/` — 매뉴얼/VOC/커맨드/설정 관리 콘솔.

> 이 저장소는 **공개용 사본**이다. 서버 주소·계정·경로는 전부 자리표시자로 바꿔 두었고
> (`10.0.0.30`, `ops.user`, `/home/users` 등), 실제 값은 배포 환경의 `.env`와 설정 DB에만 있다.
